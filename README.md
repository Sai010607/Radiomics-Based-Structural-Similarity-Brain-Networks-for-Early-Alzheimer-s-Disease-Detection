# Brain Network Evolution Analysis Across Alzheimer's Disease Stages

## Overview

This project investigates how brain connectivity patterns evolve across the progression of Alzheimer's disease using MRI-derived radiomic features.

Correlation-based brain networks were constructed for five clinical stages:

* Normal
* EMCI (Early Mild Cognitive Impairment)
* MCI (Mild Cognitive Impairment)
* LMCI (Late Mild Cognitive Impairment)
* AD (Alzheimer's Disease)

For each stage, network topology was analyzed using graph-theoretic metrics including edge count, network density, and average correlation strength.

The study was accepted for presentation at INCAM 2026.

## Methodology

1. Extract radiomic features from multiple brain regions.
2. Separate subjects according to disease stage.
3. Compute stage-specific feature correlation matrices.
4. Construct brain networks using correlation thresholding.
5. Calculate graph metrics.
6. Visualize network evolution across disease progression.

## Brain Regions Analyzed

* Brainstem (BS)
* Corpus Callosum (CC)
* Cerebrospinal Fluid (CSF)
* Gray Matter (GM)
* Hippocampus (HIPPO)
* Midbrain (MB)
* Ventricles (VENT)
* White Matter (WM)

## Network Metrics

For each stage, the following metrics were computed:

* Number of Edges
* Network Density
* Average Correlation Strength
* Hub Regions

## Key Findings

The analysis demonstrates stage-dependent alterations in network organization across multiple brain regions.

Distinct changes in network density and connectivity strength were observed from Normal through AD stages, indicating progressive disruption of brain connectivity patterns during Alzheimer's disease progression.
